# 🤖 AI Study Assistant

An AI-powered desktop study application built with **Python**, **Tkinter**, and **Groq AI**.

The AI Study Assistant helps students organize notes, ask AI questions, generate summaries, create flashcards, practice quizzes, and build personalized study plans—all inside a simple desktop application.

---

# ✨ Features

## 📚 Note Management
- Add Notes
- View Notes
- Edit Notes
- Delete Notes
- Search Notes
- Organize notes by subject

---

## 🤖 AI Features

### 💬 Ask AI
Ask any study-related question and receive an AI-generated explanation.

### 📝 AI Note Summarizer
Generate short, easy-to-understand summaries from your notes.

### 🧠 AI Flashcard Generator
Automatically create study flashcards from your notes.

### 🎯 AI Quiz Generator
Generate multiple-choice quizzes based on your notes.

### 📅 AI Study Planner
Create a personalized study schedule based on:
- Subject
- Days remaining until the exam

# 🚀 Installation

## 1. Clone the repository

```bash
git clone https://github.com/muhilvannan16/AI_Study_Assistant.git
```

## 2. Navigate into the project

```bash
cd AI_Study_Assistant
```

## 3. Install the required packages

```bash
pip install -r requirements.txt
```

---

# ▶️ Running the Project

Launch the GUI application:

```bash
python gui.py
```

Or run the console version:

```bash
python console_version.py
```
